# Ecosystem Chat Preview — Transaction Boundary

## Intake boundary
A bounded capability-interface scenario with named intended capability/provider classes, permitted source material and an accountable customer observer. Preview scope must distinguish implemented source contracts from live provider execution.

## Deliverables
Source-demonstrated conversational capability mapping, provider/capability provenance model, governed invocation/reconciliation design walkthrough, applicable source artifacts and an explicit implementation-gap report.

## Exclusions
No claim of live distributed multi-LLM execution, live AI SiteFlow integration, external provider credentials, real render receipt, or completed native Ecosystem Chat LLM.

## Acceptance
Complete when the agreed scenario is mapped through the released source-positioning contract and the customer receives the implemented-vs-unproven boundary and supporting evidence.

## Commercial terms
Preview/evaluation fee, workshop scope, support, data handling and any future integration work are separately quoted. No production hosted-chat service or provider consumption entitlement is implied.

## Evidence / receipt
Retain source contract/version coordinates, provider/capability mapping, evidence references and delivery/acceptance record.

## Unreleased substrate not sold
The released Site scope positioning is not a released Ecosystem Chat runtime product. Live distributed execution and live AI SiteFlow integration remain NOT YET IMPLEMENTED / NOT PROVEN.
